# Audio & MIDI API Projects

A central hub for some of my experimental browser-based audio tools, sequencers, and MIDI utilities. Most projects here are built using Web Audio APIs and explore different methods of generative sound design, sequencing, and synthesis.

## Sequencers & Synthesisers

*   **[SQ_12](https://github.com/josev2046/SQ_12)**
    A 12-step control voltage generator and monophonic synthesiser designed as a tribute and homage to classic 1970s Japanese electronic instruments — most notably akin to the legendary Korg SQ-10.

*   **[SQ-24](https://github.com/josev2046/SQ-24)** 
    *(Work in Progress)* A browser-based, two-sequencer synth. Each sequencer has 12 steps (extendable to 24), and the whole panel can run as one voice with Sequencer 2 modulating Sequencer 1.

*   **[SQ_2046](https://github.com/josev2046/SQ_2046)**
    A 16-step sequencing environment that fuses two independent monophonic synths with a three-part analogue-style drum machine.

## Radial Tools & Generative Sound

*   **[RP-25](https://github.com/josev2046/RP-25)**
    The RP-25 Radial Pitch Mapper is a browser-based utility designed to generate precise reference tones for tuning unquantised analogue sequencers and synthesisers.

*   **[VW-R1](https://github.com/josev2046/VW-R1)**
    An experimental radial sequencer for generative sound design, running the Web Audio API and non-linear Euclidean algorithms.

## Rhythm & Groove

*   **[VW-D16](https://github.com/josev2046/VW-D16)**
    A pure Web Audio API bridge between classic TR-style x0x drum machines and modern performance grooveboxes.

*   **[VW-CP12](https://github.com/josev2046/VW-CP12)**
    A dynamic radial polyrhythm engine dedicated to the foundational rhythms of flamenco.

## Experiments & Miscellaneous

*   **[electric-cafe](https://github.com/josev2046/electric-cafe)**
    A collection of experiments and sound explorations with my synths.
