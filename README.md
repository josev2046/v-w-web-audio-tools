# Audio & MIDI API Projects

A central hub for my experimental audio tools, sequencers, and MIDI utilities. Built primarily with the Web Audio API, these projects explore generative sound design, sequencing, and synthesis natively in the browser. 

*Note: Several projects now feature a **DAW iteration** with WAV recording and experimental MIDI capabilities. The groovebox (SQ_2046) and drum machine (VW-D16) also support individual stem and master export.*

## Sequencers & Synthesisers

*   **[SQ_12](https://github.com/josev2046/SQ_12)** | **[DAW Iteration](https://josev2046.github.io/SQ_12/DAW.html)**
    A 12-step control voltage generator and monophonic synthesiser paying homage to classic 1970s Japanese electronic instruments, akin to the Korg SQ-10.

*   **[SQ-24](https://github.com/josev2046/SQ-24)** 
    *(Work in Progress)* A dual-sequencer synth. Each 12-step unit is extendable to 24, allowing the entire panel to run as a single voice with cross-modulation.

*   **[SQ_2046](https://github.com/josev2046/SQ_2046)** | **[DAW Iteration](https://josev2046.github.io/SQ_2046/daw.html)**
    A 16-step groovebox fusing two independent monophonic synths with a three-part analogue-style drum machine.

## Radial Tools & Generative Sound

*   **[RP-25](https://github.com/josev2046/RP-25)** | **[DAW Iteration](https://josev2046.github.io/RP-25/daw.html)**
    The Radial Pitch Mapper generates precise reference tones for tuning unquantised analogue hardware.

*   **[VW-R1](https://github.com/josev2046/VW-R1)** | **[DAW Iteration](https://josev2046.github.io/VW-R1/daw.html)**
    An experimental radial sequencer for generative sound design, driven by non-linear Euclidean algorithms.

## Rhythm & Groove

*   **[VW-D16](https://github.com/josev2046/VW-D16)** | **[DAW Iteration](https://josev2046.github.io/VW-D16/daw.html)**
    A drum machine bridging classic TR-style x0x units with modern performance workflows.

*   **[VW-CP12](https://github.com/josev2046/VW-CP12)** | **[DAW Iteration](https://josev2046.github.io/VW-CP12/daw.html)**
    A dynamic radial polyrhythm engine dedicated to foundational flamenco rhythms.
